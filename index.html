IISD-ELA Core Data on Repositories

Many IISD-ELA core datasets are available on repositories.
  • Sometimes one repository data package contains multiple datasets, as evident in the specified metadata info sheets.
  • The Environmental Data Initiative data packages are linked to the ID for all versions (choose the most recent; each version has its own DOI).
  • The DataStream datasets are linked to a DOI which applies for all versions (version must be specified when cited by the data user).

Date Ranges and Update Information

  • Some packages' data content varies between the EDI and DataStream versions, due to differing repository requirements.
  • The information below corresponds to the EDI packages.
  • Where dates differ between EDI and DataStream, this is indicated with an asterisk (*) at the end of its name, below.
  • To see the DataStream date ranges, check the datasets themselves, or the difference may be explained in the abstract of either package.
